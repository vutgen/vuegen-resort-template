# Resort Landing Template

Лендинг-шаблон для курортов, отелей и курорт-городов. Чистые HTML/CSS/JS, без сборки.

## Как адаптировать под клиента

Весь контент и тема лежат в одном файле — `config.js`:

- название, слоган, тексты, контакты, соцсети;
- цвета и шрифты (`theme`);
- секции: номера, активности, галерея, акции, отзывы, расположение (метка на карте по `lat` / `lon`), FAQ;
- пустой массив или поле — секция не показывается;
- фото кладутся в `img/`, пути прописываются в конфиге.

Форма бронирования подключается к движку клиента через `booking.action`, форма заявки — через `contacts.formAction`.

## Запуск

```
python3 -m http.server 8080
```

и открыть http://localhost:8080
